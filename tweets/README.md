# Tweets Extension

A Pi extension for capturing, searching, and viewing tweet threads stored in local SQLite database (`~/.pi/tweets/tweets.db`).

## Features

- **post_tweet**: Post a tweet to share thoughts, technical insights, design decisions, progress updates, discoveries, or reflections.
- **reply_tweet**: Reply to an existing tweet thread to continue thoughts, log progress, or resolve issues.
- **search_tweets**: Search past tweets by keyword or tags for the current repository.
- **/tweets-ui**: Launch Express web UI at `http://localhost:3000`.
