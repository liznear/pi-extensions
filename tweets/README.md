# Tweets Extension

A Pi extension for capturing, searching, and viewing tweet threads stored in local SQLite database (`~/.pi/tweets/tweets.db`).

## Features

- **post_tweet**: Post a tweet with optional tags.
- **reply_tweet**: Reply to an existing tweet thread.
- **search_tweets**: Search tweets by keyword.
- **/tweets-ui**: Launch Express web UI at `http://localhost:3000`.
